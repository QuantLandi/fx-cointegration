# IRFA submission checklist

Target: *International Review of Financial Analysis* (Elsevier). Initial submit uses **Your Paper Your Way** — a clear PDF is enough; camera-ready Elsevier layout is not required at first submission.

Re-check the live guide on submit day:
https://www.elsevier.com/journals/international-review-of-financial-analysis/1057-5219/guide-for-authors

## Upload bundle

| Item | File | Notes |
|------|------|--------|
| Manuscript | `paper/main.pdf` | Built from `paper/main.typ` |
| Highlights | `paper/highlights.txt` | 3–5 bullets, ≤85 characters each |
| Source (optional) | `paper/main.typ`, `paper/refs.bib` | Keep for revisions; upload if EM asks |
| Figures | Embedded in PDF | Separate art files only if Editorial Manager requests them |
| Cover letter | TBD | Next workstream after this format pass |
| Replication | https://github.com/QuantLandi/fx-cointegration | Cited in the Data/code availability note |

## Front matter already in the PDF

- Abstract + keywords
- JEL: C58, F31, G11, G15
- Data/code availability + conflict of interest (end matter)

## Out of this checklist

- SSRN PDF refresh (after this PDF is final)
- Cover letter (JAE history, EG defense, retargeting pitch)
- Optional robustness (Johansen, swap costs)
